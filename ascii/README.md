## Build
`python3 make-ascii.py`

## Deploy
`http-server -c-1 dist`

## Usage
- Drag the green slider (on the left side of the screen) to expose the ASCII rendered image.
- Use the controls at the bottom of the canvas to change characteristics about the ASCII rendering.
- Pressing buttons 1, 2, and 3 on your keyboard will switch between different animations (geometries, solar system, video).
- To upload a video for video mode, you can hit Choose File.
- Pressing +/- will increase/decrease the font size (you can also use the slider on the bottom).

## Known Issues
- Vertical lines sometimes appear between character boundaries
- Making font size too small will cause characters to be illegible
- Making font size too big increases lag
